# lhg-deep-research 标准冒烟用例

自检命中疑似缺陷、或用户要求验证时运行。以下用例通过才算冒烟通过。

## 用例 R-1：小样本调研完整性
输入主题："GitHub MCP 相关 skill Top 5"。

期望输出结构齐全：
- 清单表：排名、名称、star 数（标注核实日期 YYYY-MM-DD）、许可、作者、一句话简介，每条保留来源 URL
- 头部深挖：作者背景、动机证据链；无法核实的标注"未找到公开信息"，不得编造
- 每类复刻/优化/超越方案：含可复刻性评估（门槛/依赖/许可）
- 跳过项：如有隐私/侵权/灰色内容，单列并说明原因
- 数据口径说明：数据日期、核实方式

## 通过标准
- 结构无缺项；所有数字标注日期；无编造内容（抽查一条作者背景断言必须有证据链）；许可判断有依据。任一项不满足即冒烟失败。
